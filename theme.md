# Flowbase UI Theme

## Direction

Flowbase should feel fresh, cozy, modern, and clean. The product is a working
space first: calm enough for notes, structured enough for tasks, and lively
enough for whiteboards and AI tools.

## Color Palette

- Base canvas: cool mist surfaces with high-contrast slate text.
- Primary action: deep slate for dependable command buttons and focus states.
- Fresh accents: sky, emerald, rose, amber, cyan, indigo, and violet for
  navigation icons, tags, and small status cues.
- Panels: white or near-white layers with soft borders instead of heavy shadows.
- Avoid a dull monochrome cozy palette. Warmth should come from selective color,
  rounded detail, and gentle contrast rather than beige-heavy screens.

## Typography And Density

- Use the system sans stack with readable 14px body text and compact 11px to
  12px metadata labels.
- Use medium or semibold weight for headers and commands.
- Keep utility surfaces compact: 8px radius, concise labels, and stable icon
  button dimensions.
- Prefer quiet hierarchy over oversized dashboard headlines.

## Spacing And Layout

- Sidebar navigation should be denser than the workspace area.
- Use 4px to 8px gaps within compact controls and 16px to 24px gaps between
  workspace sections.
- Keep panels aligned to a practical grid with enough whitespace for scanning.
- Use borders, subtle tint changes, and focused color cues to separate surfaces.

## Sidebar Guidance

- Expanded navigation shows logo, app name, group labels, colorful Lucide icons,
  text labels, and footer context.
- Collapsed navigation keeps icon-only access with tooltips or accessible names.
- Group items by workspace intent so a longer product menu still feels small.
- Active navigation should be obvious without overpowering nearby items.

## Component Guidance

- Prefer icon-led controls for compact actions and text buttons for primary
  commands.
- Reuse shared theme tokens before adding one-off colors.
- Use cards for bounded tools or repeated items, not nested page framing.
- Validate responsive layouts so text, sidebars, and preview surfaces do not
  overlap on narrow screens.
